# Paparats 0.1.0 — the real catalog

Paparats now installs real apps. 53 apps, each straight from its authors' GitHub Releases:
OBS Studio, Obsidian, KeePassXC, PowerToys, ShareX, VSCodium, 7-Zip and more, plus the Rising
shelf of 23 young projects worth meeting, such as OpenPencil, photocraft, Handy and RapidRAW.

- Every file is checked against the SHA-256 the signed catalog pins, and installers against
  their author's signature. When an author signs nothing, the app page says so.
- Paparats finds the apps you already have and shows their updates. The catalog refreshes in
  the background as often as Settings › Updates says.
- App pages show the project on GitHub: stars, the project's age, the website and links to
  support the author.
- Open and Open install folder work.
- No ads, no telemetry, no account. The app talks only to GitHub (see PRIVACY.md).

The demo world of 0.0.1 is still there: start `Paparats.exe --demo`.

Paparats теперь ставит настоящие программы: 53 штуки, каждая — прямо из GitHub Releases
авторов. Среди них OBS Studio, Obsidian, KeePassXC, PowerToys, ShareX, VSCodium и 7-Zip, а на
полке «Подающие надежды» 23 молодых проекта, например OpenPencil, photocraft, Handy и RapidRAW.
Каждый файл сверяется с SHA-256 из подписанного каталога, установщики — с подписью автора.
Paparats находит уже установленные программы и показывает обновления. Никакой рекламы,
телеметрии и аккаунтов: приложение обращается только к GitHub.

The installer is not code-signed yet, so Windows SmartScreen may warn you: choose
"More info" → "Run anyway".
