# Paparats 0.0.1 — demo

The first public build. It runs the demo world from the design: every screen, both themes and
three languages work, but the catalog, the installs and the account are simulated. Nothing is
installed on your PC yet. Real installs from the authors' GitHub Releases come with 0.1.0, and
this build updates itself to it.

Первая публичная сборка, демо-версия: все экраны, обе темы и три языка работают, но каталог,
установки и аккаунт пока имитация, на компьютер ничего не ставится. Настоящие установки из
GitHub Releases авторов появятся в 0.1.0, и эта сборка обновится до неё сама.

The installer is not code-signed yet, so Windows SmartScreen may warn you: choose
"More info" → "Run anyway".
