# Paparats 0.1.1

- "Open" now starts apps installed from MSIX packages (Seelen UI) and apps whose Windows entry
  names no program (Anki, Audacity, Flow Launcher, Kando, Luanti, OpenLogi, PowerToys,
  Stellarium): it uses their Start-menu shortcut or the program named like them.
- Uninstalling an app with an Inno Setup uninstaller leaves its log in %TEMP%, to see why when
  Windows still lists the app afterwards.
- Updated dependencies.

Every app in the catalog now goes through a weekly check on Windows Server 2022 and 2025:
install, update from its previous release, found by Paparats, something for "Open" to start,
uninstall.

«Открыть» теперь запускает и программы из пакетов MSIX (Seelen UI), и те, чья запись в Windows
не называет программу (Anki, Audacity, PowerToys и другие): через ярлык в меню «Пуск». Удаление через
деинсталлятор Inno Setup оставляет журнал в %TEMP%. Обновлены зависимости.

The installer is not code-signed yet, so Windows SmartScreen may warn you: choose
"More info" → "Run anyway".
